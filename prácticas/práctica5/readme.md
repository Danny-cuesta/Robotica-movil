# PRÁCTICA 5: Robot que construye un mapa en un almacén industrial

## OBJETIVO DE LA PRÁCTICA

El objetivo de este ejercicio es desarrollar un algoritmo de navegación que permita a un robot explorar de forma autónoma un entorno de almacén mientras genera un mapa 2D preciso del entorno utilizando datos de sensores LIDAR.
