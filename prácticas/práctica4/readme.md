# PRÁCTICA 4: Navegación global con algoritmo GPP, plan como recurso


## OBJETIVO DE LA PRÁCTICA 

El objetivo de esta práctica es implementar un algoritmo de Planificación de Ruta de Gradiente (GPP), una vez seleccionado un destino, el algoritmo GPP se encarga de encontrar el camino más corto hacia él, evitando, en este nuestro caso, todo lo que no es camino, deberá seguir esta trayectoria y alcanzar el objetivo en el robot.
